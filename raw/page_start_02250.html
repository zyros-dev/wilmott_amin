This functions takes as arguments joint observations of NDim correlated random variables. And returns a multidimensional hermite series in NDim dimensions expanded to Order-th Hermite polynomials of(Order is a parameter input argument to this function) NDim orthogonal Z's. 
Order parameter in input arguments means order of highest hermite polynomials in hermite series expansion. 1st variable has a one dimensional hermite series in one orthogonal normal random variable. 2nd variable has a two dimensional hermite series in first two orthogonal normal random variables. While nth variable has an n dimensional hermite series in terms of n orthogonal standard normal random variables.%
Suppose there are Ndata number of joint observations of multidimensional random variables, then probability mass associated with each of the observations is 1/Ndata.
First we regress each random variable on "Ideal Normal Measure" which is composed of a grid with Ndata grid cells spanning over standard normal  density so that each of the Ndata cells in the grid have a probability mass equal to probability of 1/Ndata that is probability of one observation of data. Again the idea is that we use the same number of normal density grid cells, ZI, as the number of data observations and normal density grid is constructed so that it shares the 1/Ndata probability associated with each observation. The idea is that if data is a true polynomial function of  standard normal density and its(of random variable to be regressed) first derivative with respect to standard normal does not switch sign, We can sort the data observations in increasing order and regress them on standard normal grid, ZI, in same increasing order and we expect that regression would capture any systematic polynomial function of data that lies in span of the hermite polynomials used in regression while any random deviations that are orthogonal to span of the hermite polynomials would remain in unexplained variance.
