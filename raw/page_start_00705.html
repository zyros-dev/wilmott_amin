All the above graphs have been made with Ito-Taylor tree method. And we analytically compute the hermite polynomials weights for a particular SDE in terms of initial value parameter i.e starting value of the SDE variable, X0. Then we start an Ito-Taylor tree for the SDE from origin. Each branch of Ito-Taylor tree is like an ODE for a particular value of the standard normal variable. And we re-compute the coefficients given the new initial values for every branch along the Ito-Taylor tree for every time grid. We have to account for variances.
Basically Ito-Taylor tree method is just converting an SDE evolution into ODE-like evolution where each ODE evolves with the particular value of normal assigned to the specific branch of Ito-Taylor tree.
I have lumped together all time calculations into calculation of hermite polynomial weights and later I solely use variances of standard normal random variable without any further consideration of time values. 
In the previous post, some graphs diverge from true solution when certain tree-paths (or ODE paths) get closer to zero and this can be easily tackled by selectively decreasing the step size for ODEs(for the specific branch of Ito-Taylor tree that has gotten close to zero) in the Ito-Taylor tree when they reach close to zero. Paths diverge from true solution mostly for diffusions that have a CEV parameter gamma close to .5

I have used variance of 1/Tt for one step evolution (along the Ito-Taylor tree evolution) of normal random variable where Tt are total number of time steps so at the terminal time variance becomes 1 (one) when added over all the time steps and we can map the evolution of the SDE on a standard normal density. In the modified program I attached on post 705, you could see that density of SDE is calculated by change of variable with respect to a standard normal.
However if you want to find the density at any intermediate time point, you could easily do so by using the density of normal random variable with variance parameter (standard deviation to be precise) [$]\sqrt{\frac{Tt}{n}}[$] where n is the time level where we are finding the density. For example to find the density at time level 2 (or after two time steps) where Tt are total time levels/steps, you could simply use the normal random variable density with variance parameter or standard deviation equal to [$]\sqrt{\frac{Tt}{2}}[$] and thus you could easily continue to calculate the density along every time point on the Ito-Taylor tree evolution.  There could also be several other ways to map the evolution of SDE density on density of normal random variable and these minor details will continue to change with different possible algorithms.
In fact, you can construct this Ito-Taylor tree with only first two hermite polynomials and taking a step size small enough and it would work. For many SDEs, I found no significant difference when I used a step size of .0625 with two hermite polynomials as compared to solution with four hermite polynomials with .0625 step size. Of course, when SDE parameters go to extreme, you might have to use larger number of hermite polynomials or a smaller step size. When gamma=.5, in that case taking just two hermite polynomials is more stable closer to zero than working with first four hermite polynomias in Ito-Taylor expansion.
I will soon be posting another very simple matlab program based on just two hermite polynomials so that most friends would not have to worry about any high dimensional expansions. And it could simply be extended to four hermite polynomials when needed. No special need for very high dimensional hermite expansions.

Here is an Ito-Taylor tree matlab program based on only first two hermite polynomials. This is just a first initial version but I decided to post it. You can change the program in all sort of interesting ways. And you will have to rescale the axes in matlab many times. I have compared the output from Ito-Taylor tree to analytical solution for the SDE dX=mu0 * X(t) *dt + sigma0 * X(t)^gamma *dz(t)
Please note that analytical solution given in the program can be compared with Ito-Taylor solution only when beta=1 in the program. I have taken a very small step and used 64 time intervals per year. Green line in graph is Ito-Taylor solution and red line is analytical solution.
Here is the program.
Code: Select all
function [] = SDEdensity()
x0=.50;
mu0=.15;
sigma0=.55;
beta=1.0;
gamma=.85;
dt=.0625/4;
Tt=64*2;
T=Tt*dt;
Nn=81;
IdtdzN=1/sqrt(3.0)*dt^1.5;
IdzdtN=(1-1/sqrt(3.0))*dt^1.5;
Idtdt0=dt^2/2.0;
IdzdzN2=.5*dt;
Idzdz0=-.5*dt;
Idt=dt;
Idz=sqrt(dt);
for nn=1:Nn
    X(nn)=x0;
end
for tt=1:Tt 
    for nn=1:Nn
        zz(nn) = (nn*.1 - 4.0);
        HCoeff(nn,1)=mu0*X(nn)^beta*Idt+mu0^2.0*beta*X(nn)^(2*beta-1)*Idtdt0+ ...
            sigma0^2*gamma*X(nn)^(2*gamma-1)*Idzdz0+.5*beta*(beta-1)*mu0*sigma0^2*X(nn)^(beta+2*gamma-2)*Idtdt0;
        HCoeff(nn,2)=sigma0*X(nn)^gamma*Idz+mu0*sigma0*beta*X(nn)^(gamma+beta-1)*IdzdtN+ ...
            sigma0*mu0*gamma*X(nn)^(gamma+beta-1)*IdtdzN+ .5*gamma*(gamma-1)*sigma0^3*X(nn)^(3*gamma-2)*IdtdzN;
        HCoeff(nn,3)=sigma0^2*gamma*X(nn)^(2*gamma-1)*IdzdzN2;
        X(nn)=X(nn)+HCoeff(nn,1)+HCoeff(nn,2)*1/sqrt(Tt)*zz(nn)+HCoeff(nn,3)*(1/sqrt(Tt)*zz(nn))^2.0;
    end
end
CFlag = 1;
for nn = Nn - 1:-1:2 
  if((X(nn) > X(nn - 1)) && (CFlag == 1))
      nnStart = nn;
  else
     CFlag = 0;
  end
end
for nn=nnStart:Nn-1
   zz(nn) = (nn*.1 - 4.0);
   Dfx(nn)=(X(nn+1)-X(nn-1))/(zz(nn+1)-zz(nn-1));
end
for nn=nnStart:Nn-1
    fx(nn)=normpdf(zz(nn),0,1)/Dfx(nn);
end

Nn2 = 2000;
gamma0 = gamma - 1;
X0 = x0;
if(mu0~=0)
    tau=(exp(2*mu0*gamma0*T) - 1)/(2*mu0*gamma0);
else
    tau=T;
end
for n = 1:Nn2 
  yy(n) = (.0002 + n*.0050); 
  yy1(n) = (.0002 + n*.005)*exp(-mu0*T);
  fyy(n) = exp(-mu0*T)*yy1(n)^(-2*gamma0 - 3/2)*x0^(.5)/(sigma0^2*abs(gamma0)*tau)* ...
      besseli(abs(1/(2*gamma0)), (yy1(n)^(-gamma0)*x0^(-gamma0)/(sigma0^2*gamma0^2*tau)))* ...
     exp(-1*(x0^(-2*gamma0) + yy1(n)^(-2*gamma0))/(2*sigma0^2*gamma0^2*tau));
end
fyy;
plot(X(nnStart:Nn-1),fx(nnStart:Nn-1),'g',yy(1:Nn2),fyy(1:Nn2),'r');
end

Though I hope there will be interesting uses of the new Ito-Taylor tree method, some new possibilities also open up with this method. For example, in SDEs literature, it is almost always assumed that noise scales as square root of time as in Brownian motion. Though this might be intelligent in most of the situations, there is nothing there to say that this must always be the case. In many SDEs modelling physical phenomenon, noise might as well scale as .25 power of time interval or possibly .75 power of time interval and we can very easily solve those SDEs with different time scaling with this new method. Time scaling must not necessarily be related to Brownian motion and when it is actually not, we can use the new method to solve other SDEs that arise with different time scaling in the random noise.

Here I copy the post.
Converting An SDE into Autonomous ODEs: The Ito-Taylor Tree Method for Solution of SDEs

In my new research on the solution of SDEs and their stochastic integrals, I have worked with a new Ito-Taylor tree method for calculation of densities of SDEs and their path integrals. In this method, we start an Ito-Taylor tree for the SDE with a few branches and each branch is associated with a certain value of standard normal random variable and the tree branches just once at origin/starting value of SDE . Each branch of Ito-Taylor tree is like an ODE for a particular value of the standard normal variable and each branch of the tree evolves in time autonomously and never re-branches save once at origin. And we re-compute the Ito-Taylor coefficients given the new initial values of X for every branch along the Ito-Taylor tree for every time level. Basically, Ito-Taylor tree method is just converting an SDE evolution into ODE-like evolution where each ODE evolves autonomously with the particular value of normal assigned to the specific branch of Ito-Taylor tree.
The method is lightning fast since the tree branches once at origin and never branches after that. In the accompanying matlab program, I have taken only 81 branches that span a standard normal between -4 and +4 with a normal gird spacing of .1 and there are only 64 time steps per year and one step computational effort for every branch is roughly comparable to monte carlo simulation computational effort for one single path. So you can yourself imagine how super-fast the method is. Its speed is roughly comparable to monte carlo with only 81 paths.
I have posted an initial version of Ito-Taylor tree matlab program based on only first two hermite polynomials that you can download. You can change the program in all sort of interesting ways. And you will have to rescale the axes in matlab many times. I have compared the output from Ito-Taylor tree to analytical solution for the SDE
dX=mu0 * X(t)^beta *dt + sigma0 * X(t)^gamma *dz(t)
Please note that analytical solution(from Schroeder's formula/its time changed version) given in the program can be compared with Ito-Taylor solution only when beta=1 in the program. I have taken a very small step and used 64 time intervals per year. Green line in graph is Ito-Taylor solution and red line is analytical solution.
You can download and freely distribute the matlab program for calculation of density of SDEs using this new method. There is a lot of information I posted about the new method on Wilmott.com math finance web site in past few days. I have posted a very simple matlab program that you can download from post 709 on wilmott.com mathematical finance forum here: viewtopic.php?f=4&t=99702&start=705 or from nuclearphynance.com forum here: http://nuclearphynance.com/Show%20Post. ... Key=180518
Sometimes, when parameters of SDE are extreme, you might want an Ito-Taylor tree with first four hermite polynomials instead of just two that I used in the program and you could then also take a larger step. Larger step might not have much of an advantage since we are working with only a hundred or so paths. And sometimes, when stability issues arise, you could use the method with just one polynomial.
Almost the density of any SDE can be found by this method. I have written the following program for CEV-like diffusion and lognormal-like drift because it can be analytically evaluated with Schroeder's formula. But you can find the density of almost any SDE with mean-reversion and so many other features. You could also calculate the densities of path integrals of these stochastic volatility SDEs and plug those values in lognormal or CEV formula.

And it could simply be extended to four hermite polynomials when needed. No special need for very high dimensional hermite expansions.
As I have mentioned, there could be a very large number of ways to choose the variance for each step normal but it will certainly have to be equal over the steps. So it would have to be the same algorithm that I have used in the matlab program posted but there could be more efficient ways to choose the variance for each step.
I will follow in a day or two with detailed latex equations explaining the algorithm. And it is absolutely no more difficult and in fact almost identical to monte carlo simulations with hermite polynomials. All that is different that you do not use a random number generator and instead use the same particular value of normal variable assigned to each branch of the Ito-Taylor tree all along the time evolution of the particular branch. I weighted the normal value with sqrt(1/Tt) weight and choice of this weight makes a slight difference in how each branch gets mapped on the standard normal density. Again this weight could be changed and would result in a slightly more efficient or less efficient algorithm. 
In my implementation, I divided normal density into 81 parts associated with each branch of the tree, starting from -4 and going to +4 with a spacing of .1, so the first branch of the Ito-Taylor tree will use a value of normal -4, all along its evolution for each time step and rest of the algorithm is exactly the same as monte carlo simulation and they differ only in 
1. that I use a normal value of -4 for first branch instead of any randomly generated value (as in monte carlo). For the second branch, I would use a normal value of -3.9 instead of any randomly generated normal value and so on with a normal value of +4 for the 81st branch. And of course normal value of zero for 41st branch.
2. I use a weight for this normal value assigned to each branch, and I have set this weight equal to sqrt(1/Tt) in my algorithm and there could be many other possible choice of weights that would work. But for all branches of the tree,these weights would have to be the equal and same for every time interval when these time intervals are equal. There could be many ways of choosing these equal weights and mapping them on normal density with reverse varaince.
And when I reach a step where density has to be calculated, We use the inverse of square-root of squared weights used over all the previous time intervals in the density. Since I used a weight of sqrt(1/Tt) for each interval when there are Tt time intervals, sum of their squared values would go to one and it would be mapped on a standard normal density.
3. As opposed to monte carlo, the final values of the SDE density have to be calculated by doing a change of variable derivative with normal density of appropriate variance(this variance is unity in my implementation since sum of squres of sqrt(1/Tt) sums to one over Tt time intervals). Since we have chosen equal spacing of normal values along different branches of the trees, this can be easily calculated using the finite difference derivative formula for equi-spaced grids.
All of the above is valid when we calculate the density over multiple steps such that sum of squared weights (sqrt(1/Tt) in my implementation) over all steps have summed to unity. But we would like to be able to calculate the density along all the time steps in the evolution. And that is where an intelligent choice of weights and grid could help. I will explain this part in greater detail tomorrow.
