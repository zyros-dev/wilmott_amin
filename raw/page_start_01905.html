Friends, I tried to improve the program and put it on a more sound logic and I have been able to get good initial prototype for iterative optimization by perturbing the parameters.
Basic logic is:For parameters with highest sensitivities to Objective Function at any step in optimization loop, we increase the perturbation, i.e. change in parameters(we accelerate them). and For parameters with least sensitivity, we decrease the perturbation, i.e change in parameters i.e decelerate them. And this acceleration/deceleration is further increased or decreased at each time step based on whether global sensitivity to objective function is increasing or decreasing at each time step. When there is no change in objective function from any parameter on some optimization step, all parameters are decreased by a ratio(of .85) in my program. All acceleration/deceleration is applied in extremely small ratios very smoothly.
I explain it below.
Here is the algorithm for optimization. 
There are seven coefficients. The way we have set up the problem, the first coefficient is automatically adjusted to keep the variance standard while c0 is fixed based on other coefficients so that the density has zero mean.
So we are left with optimization solution over six coefficients. 
I choose an initial change in coefficients or their speed which is given as DeltaX which is a vector that has seven elements(one of them is not being used for six parametr optimization). I noticed when the series is in hermite form variance associated with seventh hermite polynomial is factorial of seven and so on for each hermite polynomial so I chose initial speed or change in coefficients roughly inversely proportional to multiplier associated with its variance (though I used a slightly different form in the program.)
I chose this DeltaX as 

for nn=1:SeriesOrder
    DeltaX(nn)=.00125/(factorial(nn)).^(.75);
end

DeltaX is first order change or speed of coefficients in optimization. At each iteration I sorted the coefficients in descending order with respect to their sensitivity on objective function. I increased the speed of first three coefficients with highest sensitivity and decreased the speed of three coefficients with smallest sensitivity. This is approximate and can be improved. This is done in the program as (in the below, ddX(n) is proportional acceleration as the change in the sped of nth coefficient.
to increase speed, acceleration is applied as
DeltaX(n)=DeltaX(n)*(1+ddX(n));
to decrease speed, decleeration is applied as
DeltaX(n)=DeltaX(n)/(1+ddX(n));

So we give acceleration to first three parameters with largest sensitivty and deccelrate the parameters with smallest sensitivity.
Again this acceleration/decelration is different for each parameter. Initial value of acceleration/deceleration are given as (below indices are sorted with respect to sensitivity and and are not initial natural indices of coefficients. index 1 in below is coefficient with largest sensitivity to objective function while index 6 is index with smallest sensitivity to objective function) 
ddX(1)=.005;  %acceleration applied to highest sensitivity index
ddX(2)=.0005;%acceleration applied to 2nd highest sensitivity index.
ddX(3)=.00005;%acceleration
ddX(4)=.00005;%deceleration. speed will be divided.
ddX(5)=.0005;%deceleration
ddX(6)=.005;%deceleration applied to least sensitivity index. speed will be divided

The above are initial values of acceleration and deceleration and are chosen by trial and error to perform best.
Finally we increase or decrease acceleration according to current state of optimization problem. If highest sensitivity to objective function is increasing at each optimization step, we increase the acceleration applied to highest sensitivity index and if it is decreasing, we decrease the acceleration associated with highese sensitivity index and so on for each of the sorted (with respect to sensitivity) indices. For example I explain from code in program as
-------------------------------------------------------------------------------------------------------------------------------------------------
for nn=1:3                  %loop over three highest senstivity indices.
        if(B(nn)>BPrev(nn)) % if sensitivity of index is larger than value at previous step
            ddX(nn)=ddX(nn)*1.000025;  %very slightly increase the acceleration
        else                        % if sensitivity of index is smaller than value at previous step
            ddX(nn)=ddX(nn)/1.000025; %very slightly decrease the acceleration.
        end
 end
--------------------------------------------------------------------------------------------------------------------------------------------------
In the iterative algorithm, change in speed and acceleration are both change very slowly and smoothly and it works very well.
I am sure that this algorithm can be improved to a great extent but I think this is a good initial prototype with right basic ideas for a lot of optimizations.

Friends, it is possible in cases when eighth moment is extremely large which happens with lognormal like distributions with very long tails that the program might not calibrate properly and fit to some smaller moments might remain poor. In such cases try to further increase the weights on smaller moments in the objective function calculation function and run the same program. 
Also starting change in parameters obviously have to be a fraction proportional to the magnitude of true size of parameters themselves. So when tails are very large, we need a different relative magnitude of perturbation size for each parameter with slightly more weight given to fifth, sixth and seventh coefficient. 
In function OptimizeMomentsByIterationZseries08A, I have given two possibilities for starting perturbations size/speed and you have to de-comment the appropriate one or use something similar. These are given below as
     DeltaX(nn)=.00125/(factorial(nn)).^(.75);  %for medium tails and medium sized higher moments
    %DeltaX(nn)=.00125/(factorial(nn)).^(.2);%uncomment for lognormal like
    %extremely high skew and very large higher standard moments. For very long tails.This gives relatively higher perturbation size/speed to higher coefficients.

Friends I was thinking of the formula to find densities of sum of two arbitrarily correlated random variables with possible correlations across higher moments. 
If X and Y are two correlated variables and their densities are known, we can use this formula to find the density of sum (X+Y).
It can also apply to stochastic evolution/differential systems of the form [$]Y(t+1)\, = \, Y(t) \, + \, \Delta Y[$] where both [$] Y(t) [$] and [$]\Delta Y[$] are stochastic variables. So we can continue to analytically simulate densities of  such systems over several periods of time.
The formula is very simple.
We just need to find cross moments of all order(up to accuracy required) between two or more random variables whose sum has to be found.

2nd order cross moments would be [$]m_{X,Y}[$]
3rd order cross moments would be [$]m_{X^2,Y} \, , \, m_{X,Y^2}[$]
4th order cross moments would be [$]m_{X^3,Y} \, , \, m_{X^2, Y^2} \, , \, m_{X,Y^3}[$]

Basically all we need to do is calculate all moments including cross moments up to the degree required for our accuracy from the data.
And Expand as binomial expansion of various order and then substitute the single moments and cross moments.

[$]m_{X+Y} \, = \, m_X \, + m_Y \, [$]
[$]m_{(X+Y)^2} \, = \, \, m_{X^2} \, +\, 2 \, m_{X,Y} \, + \, m_{Y^2}\, [$]
[$]m_{(X+Y)^3} \, = \, \, m_{X^3} \, +\,3 \, m_{X^2,Y} \, + \, 3 \, m_{X,Y^2} \, + \, m_{Y^3}\, [$]
and so on for all higher moments. It is just simple binomial expansion of various orders. For three variables, it will be trinomial expansion. We just need to substitute single moments and cross-moments everywhere in binomial expansion.
Later we can convert these moments to densities using our Z-series density construction method.

As I said, we can apply it to dynamic differential stochastic systems of the form [$]Y(t+1)\, = \, Y(t) \, + \, \Delta Y(t)[$]

All we need to find is the cross-moments between [$] Y(t) \,[$] and [$] \, \Delta Y(t)[$]. But these cross moments might not be constant all the time so the method could work only if cross-moments across initial variable [$]Y(t)[$] and noise term [$]\Delta Y(t)[$] are constant in some sense(only depend on variance and we could model them as moments across standardized densities or just keep noise density standardized, compute moments and then continue to apply the changing variance and its required higher order coefficients) or if cross-moments could somehow be computed from data which is actually difficult for many time series. Usually, we will have to find a smart approximation of cross-moments that is possibly dynamic.

I think many friends might already have explored the formula but I had not thought of it in terms of cross-moments earlier.

As an application of the formula, we can use it for finding densities of large portfolios which are sums of large number of assets and then use them  in efficient frontier optimization with Merkovitz criteria. All we need are cross moments of all stocks involved which can possibly be calculated.
