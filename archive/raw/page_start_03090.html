Friends, in this post, I want to describe the Newton method setup for calculations of the correlation coefficients in Hermite polynomial associated Gaussians. As I described yesterday that for odd hermites, we start with first hermite which is simultaneously first Gaussian as well and then move to third Gaussian and then fifth Gaussian and so on.

If there are N data points available and there are K explaining variables, we will have 2N equations in the Newton regression for each hermite polynomial with one set of equations for expectation of the Hermite polynomial and second set of equations for 2nd moment/variance of the particular hermite polynomial. This is possible because we are not in linear regression framework where every equation should be the same for all data points. Rather we are in Newton root search framework in which we have to calculate the jacobian derivatives of each equation and the equation themselves can be different. The set of correlation coefficients which we are optimizing for are the same for both the expectation equations and the variance equation. 

For the calculation of correlation coefficients in Gaussian power related to each hermite, we will have 2N equations. Let us take the general case of fifth hermite and I copy its equation that I described yesterday as

Friends, before I write full-fledged Newton algorithm for correlation coefficients, it is important to have a secondary algorithm that finds a guess that is good enough to be in the Newton catchment limit for Newton algorithm to work. And tonight, I am trying to write that algorithm. 

The logic of the new algorithm is very simple. We know that sum of squared correlation coefficients including the effect of cross-correlations have to sum to one. We can use this constraint in a very interesting way to make a simple and hopefully elegant iterative optimization algorithm. We have to devise a good ingenious objective function that depends upon the fit between model and data values of hermites and their squared values. Initially, it can be weighted sum of squared differences between data and model expectations and data squared values and model squared values. 

We perturb each correlation parameter by a small value and find its effect on the objective function (this objective function depends upon all observations i.e 2N equations). After perturbing all the correlation parameters one by one, we will alter all the correlation parameters proportional to change in objective function(in the direction of increasing objective function) but in a way that unity constraint on the sum of squared correlation coefficients including the effect of cross-correlations going to one is perfectly applied and holds for all iterations. So we perturb each parameter in proportion to change in objective function while simultaneously making sure that unity constraint holds.

Even though, we have to play with 2N equations for the calculation of change in objective function for each parameter, I expect due to unity constraint, the algorithm will quickly converge to its optimum value possibly/hopefully in a few tens of iterations. And then once it is in Newton's catchment, we can use full fledged Newton to solve for the problem.

Let us solve a toy problem with four correlation parameters that are initially chosen in a way that their sum squared is already one i.e.

\[\,{\rho_1}^2\,+\,{\rho_2}^2\,+\,{\rho_3}^2\,+\,{\rho_4}^2\,=\,1\,\]

obviously so that squared sum remains unity, any changes would have to be made in a way that 

\[\,\Delta{\rho_1}^2\,+\,\Delta{\rho_2}^2\,+\,\Delta{\rho_3}^2\,+\,\Delta{\rho_4}^2\,=\,0\,\]

For this to hold, the increase in sum squared over increasing parameters has to be equal to decrease in sum squared over decreasing parameters. Suppose \(\rho_1\) and \(\rho_2\) are increasing and \(\rho_3\) and \(\rho_4\) are decreasing. Then it has to hold that 

\[\,\Delta{\rho_1}^2\,+\,\Delta{\rho_2}^2\,=\,- \left[\,\Delta{\rho_3}^2\,+\,\Delta{\rho_4}^2\,\right]\,\,\]

A simple algorithm could be to adaptively decide on the value of equal change in positive and negative sum squared and then divide it in increasing values in ratio proportional of their objective function change(Vs sum of change in objective function in all of increasing values) and also divide it in decreasing values in ratio proportional of their objective function change (Vs sum of change in objective function in all of decreasing values).

I am sure there can be many other intelligent modifications in the basic algorithm.
