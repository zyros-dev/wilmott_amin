OK, here's a great high-school example, to see if you know ODE

[$]y' = 2y /t[$]

[$]y(t_0) = y_0[$].

Consider the cases:

1. [$]t_0 \ne 0[$]
2.  [$]t_0 = 0, y_0 \ne 0[$]
3. [$] y_0 = 0[$]

4.[$] y_0 = 0, t_0 = 0[$]

Hint; 3 choices

a. unique solution
b no solution
c. infinite number of solutions.

Which is which?

Good luck. It's a make or break case.
