Friends, this is for later work in a few days but I tend to think that in order to capture dynamics of even hermites with correlated explaining variables, we need to add at least up to second order hermites in their expansions. 

For example, our current expansion is like

\[\,{\left( \rho_{1,m}\, Z_{p,1}\,+\, \rho_{2,m}\, Z_{p,2}\,+\,\ldots\,+\,\rho_{K,m}\, Z_{p,K}\,+\,\zeta_m\,Z_{\tilde{y}}\right)}^m\,\]

but it has to be like

\[\,{\left( \rho_{1,m}\, Z_{p,1}\,+\, \rho_{2,m}\, Z_{p,2}\,+\,\ldots\,+\,\rho_{K,m}\, Z_{p,K}\,+\, \tilde{\rho}_{1,m}\, \frac{H_2(Z_{p,1})}{\sqrt{2}}\,+\, \tilde{\rho}_{2,m}\, \frac{H_2(Z_{p,2})}{\sqrt{2}}\,+\,\ldots\,+\,\tilde{\rho}_{K,m}\, \frac{H_2(Z_{p,K})}{\sqrt{2}}\,+\,\zeta_m\,Z_{\tilde{y}}\right)}^m\,\]

Even if we do not take any Taylor type expansion, we need to augment our expansion of even order hermites with 2nd order hermites of explaining variables. 

Basically I suppose that we have to take variables in first multinomial expansion above and convert them into hermite polynomials after multinomial expansion and then find all their coefficients through Newton non-linear regression. These coefficients would no longer come from binomial/multinomial expansions but would be calculated directly from Newton regressions. I am very very sure that in a few weeks, we would have far more accuracy in our calculations. 

I will try to implement it after making the other changes as I mentioned for proper calculation of variance of hermites.

Friends, I believe that for small number of explaining variables like 3-7, we actually do not need any Newton regressions. We can just use least squares regressions on large number of coefficients like 50-150 for seventh hermite regression. I believe that 50-100 variables can easily be estimated if the number of paths/Data count is half a million. I really hope that this will give us extremely good fit to conditional density all over the Z=-3 to Z=3 domains.

All we need to do is to take the combinations of variables in the expansion of the multinomials we have used to describe each hermite polynomial. We do not want the coefficients in the multinomial expansions and these coefficients have to be found through linear regressions. 

With K coefficients, we have to expand the following multinomial to mth power. Keep the variable terms and find their coefficients through linear regressions.

\[\,{\left( \rho_{1,m}\, Z_{p,1}\,+\, \rho_{2,m}\, Z_{p,2}\,+\,\ldots\,+\,\rho_{K,m}\, Z_{p,K}\,+\,\zeta_m\,Z_{\tilde{y}}\right)}^m\,\]

In place of \(Z_{\tilde{y}}\) and its powers, we would use its expectation and all odd power terms would be removed from regression because of zero expectation of gaussian. We will not use the \(\rho_{k,m}\) coefficients in the expansion and will keep only the variables of each term (found in multinomial expansion) in the regressions and all the coefficients (that can be quite large) for each term would be found from linear regression.


Higher hermites are important but not that important and we can limit the number of combinations of variables in the regressions on higher hermites of Y. In a few weeks, I hope that problem would not be if we can get all the density accurately. Rather the problem would be how can we construct elegant parsimonious combinations of variables that can do the regressions and other things quickly without any loss of accuracy for large number of explaining variables.
