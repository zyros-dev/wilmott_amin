We take the following calculation of the value of derivative of 2D Z-series with respect to \(Z_y\). You will have to first convert from 2D Hermite-series to 2D Z-series and then make the following calculation.
Code: Select all
function [DValue] = EvaluateDerivativeOf2DZSeries(YCoeffZZ,Zy,Zx,Order)


DValue=0;
for nn=1:Order+1
    for mm=1:Order+1
        DValue=DValue+YCoeffZZ(nn,mm).*(nn-1).*Zy.^(nn-2).*Zx.^(mm-1);
    end
end

end

Please know that this is derivative of Ydecorr with \(Z_y\) and probability density does not come into play in this calculation (therefore hermite polynomials do not get differentiated into higher hermite polynomials.)
