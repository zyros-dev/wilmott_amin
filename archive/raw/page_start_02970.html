        Wndd=Wndd-.001.*normpdf(ZZ(nn))* ((10/5000));

About the density correction program that improves the tails of the density.

First I construct a measure of negative derivative by integrating the first derivative \(\frac{dX}{dZ} \) with a Gaussian density weight \(p(Z)\) wherever this derivative is negative. Wherever this derivative is zero, we use a small negative value in integration. The value of \(\frac{dX}{dZ} \)  when it is positive, a zero value is used in integration as it is a measure of negative derivative or zero derivative.  This weight is called Wndd which is a negative value when there is a negative first derivative and zero when the density is good. (Weight of negative density derivative). This depends on hermite coefficients of the density and is altered when hermite coefficients are altered.

Then I construct a measure of deviation of moments from base moments which is defined by its own user input weights. This is called Objective Function (Obj). This measure is also altered when hermite coefficients are altered as new value of moments associated with changed hermite coefficients is different from old value of moments with unchanged coefficients.

Then we perturb each of the nnth hermite coefficients (and calculate the initial Wndd0 which is calculated before this change once ) and also calculate the new value of Wndd(nn) . We make sure that change in hermite coefficients is in the right direction in which density is improving with smaller absolute value of Wndd(nn) which is by construction negative or zero.

We also calculate the change in moments based objective function from pre-change value of Obj0 to after the change value of Obj(nn). 

We calculate the ratio abs(Obj(nn)-Obj0)/abs(Wndd(nn)-Wndd0) and alter the hermite coefficient for which the change in moment objective function is smallest per improvement in the Wndd value. Only one out of all the hermite coefficients is altered based on smallest value of the ratio abs(Obj(nn)-Obj0)/abs(Wndd(nn)-Wndd0).
