My revised paper would be ready in a few days. Meanwhile here is a general program for nth order ODE. I have tried it on the following third order ODE.
[$]y'''=-\left(t^2-2t+5\right)y''-(t-8)y'+4y[$],   [$]y(0)=y_0=1[$],   [$]y'(0)=y'_0=0[$],  [$]y''(0)=y''_0=0[$]


Here is the mathematica code for the nth order ODEs
1. [$]\text{Clear}[t,y,\text{Zi},\text{Wi},\text{Yi},Y,\text{y0},i,\text{i1},m,n,\text{ZAns}][$]
2. [$]n=3;[$]
3. [$]\text{Array}[y,n+1,0];[$]
4. [$]y[3]\text{:=}-\left(t^2-2t+5\right)y[2]-(t-8)y[1]+4y[0];[$]
5. [$]\text{Array}[\text{y0},n,0];[$]
6. [$]\text{y0}[0]=1;[$]
7. [$]\text{y0}[1]=0;[$]
8. [$]\text{y0}[2]=0;[$]
9. [$]m=10;[$]
10. [$]Y\text{:=}\text{y0}[0];[$]
11. [$]\text{For}\left[k=1,k<n,k\text{++},Y=Y+\text{y0}[k]*\frac{t^k}{k!}\right][$]
12. [$]\text{Array}[\text{Zi},n+m-1,0];[$]
13. [$]\text{Array}[\text{Wi},n+m-1,0];[$]
14. [$]\text{Array}[\text{Yi},n+m-1,0];[$]
15. [$]\text{Array}[\text{ti},n+m-1,0];[$]
16. [$]\text{Zi}[n]=(y[n]\text{/.}t\to \text{ti}[n]);[$]
17. [$]\text{For}=0;\text{For}[k=0,k<n,k\text{++},[$]
[$](\text{Zi}[i+1]=\text{Zi}[i+1]+D[\text{Zi},y[k]]*(y[k+1]\text{/.}t\to \text{ti}[i+1]));]);];[$]
18. [$]\text{For}=\text{Zi};[$]
[$]\text{For}[k=0,k<n,k\text{++},(\text{Wi}=(\text{Wi}\text{/.}y[k]\to \text{y0}[k]))]];[$]
19. [$]\text{For}=\text{Wi};[$]
[$]\text{For}[\text{i1}=i,\text{i1}\geq 1,\text{i1}\text{--},(\text{Yi}[\text{i1}-1]=\text{Integrate}[\text{Yi}[\text{i1}],\{\text{ti}[\text{i1}],0,\text{ti}[\text{i1}-1]\}])];[$]
[$]Y=Y+(\text{Yi}[0]\text{/.}\text{ti}[0]\to t);)];[$]
20. [$]\text{ZAns}=\text{Collect}[Y,t,\text{Simplify}]\text{//}\text{PolynomialForm}[\#,\text{TraditionalOrder}\to \text{False}]\&[$]

The nomenclature of the program has changed. The indexing now starts at zero and is better to understand and relate with variables and their derivatives.  In the above program y[0] stands for y(t), y[1] stands for first derivative, y[2] stands for second derivative and so on. n represents the order of the ODE. m stands for the number of iterated integral terms involved in the series expansion. y0[0], y0[1], y0[2] stand for the initial values of y(t) and its derivatives. The series solution result is output in Capital Y as opposed to (confusing) X in previous versions. The algorithm is the same as for earlier versions but slightly better at places in indexing and names of variables.


Here is the mathematica code in text format.
1. Clear[t, y, Zi, Wi, Yi, Y, y0, i, i1, m, n, ZAns];
2. n = 3;
3. Array[y, n + 1, 0];
4. y[3] := -(t^2 - 2 t + 5) y[2] - (t - 8) y[1] + 4 y[0];
5. Array[y0, n, 0];
6. y0[0] = 1;
7. y0[1] = 0;
8. y0[2] = 0;
9. m = 10;
10. Y := y0[0];
11. For[k = 1, k < n, k++, Y = Y + y0[k]*t^k/k!]
12. Array[Zi, n + m - 1, 0];
13. Array[Wi, n + m - 1, 0];
14. Array[Yi, n + m - 1, 0];
15. Array[ti, n + m - 1, 0];
16. Zi[n] = (y[n] /. t -> ti[n]);
17. For[i = n, i < m + n - 1, i++, (Zi[i + 1] = 0;
    For[k = 0, k < n, k++, (Zi[i + 1] = Zi[i + 1] + D[Zi, y[k]]*(y[k + 1] /. t -> ti[i + 1]));]);];
18. For[i = n, i <= m + n - 1, i++, (Wi = Zi[i];
For[k = 0, k < n, k++, (Wi[i] = (Wi[i] /. y[k] -> y0[k]))]];
19. For[i = n, i <= m + n - 1, i++, (Yi[i] = Wi[i];

   For[i1 = i, i1 >= 1,i1--, (Yi[i1 - 1] = Integrate[Yi[i1], {ti[i1], 0, ti[i1 - 1]}])];
   Y = Y + (Yi[0] /. ti[0] -> t);)];
20. ZAns = Collect[Y, t, Simplify] // PolynomialForm[#, TraditionalOrder -> False] &

I had been working to include some material on solution of systems of possibly non-linear ordinary higher order differential equations in my paper. I have written some mathematica code for the solution of system of m ordinary differential equations each of which could have different order and the code would solve the system. I have tried it on a system of three second order non-linear differential equations. Here are the system ODEs and the mathematica code.

The system of three 2nd order ODEs is given as 
1.   [$]y_1''=-.5y_1'{}^2-y_1'[$],  [$]y_1(0)=0[$],  [$]y_1'(0)=2[$]
2.   [$]y_2''=-.5y_2'{}^2-y_1'y_2'-y_2'[$],  [$]y_2(0)=0[$],  [$]y_2'(0)=-3[$]
3.   [$]y_3''=-y_3'{}^2-y_1'y_3'-y_2'y_3'-y_3'[$],  [$]y_3(0)=0[$],  [$]y_3'(0)=-2[$]

Here is the paper that has analytical solution of the above system: http://file.scirp.org/pdf/AM_2014021310154871.pdf I matched the constants in the analytical solution with the initial values of derivatives for each ODE in the system as used in my code and found exactly the same series expansion for the solution as given by analytical answer in the above paper.


Here is the mathematica code for general system of m equations with each equation having its own arbitrary order.

In the code. Command 2, m is the number of ordinary differential equations in the system. n is an array which defines the order of each particular ODE in the system. In our 3 equation system, we have to initialize n[0], n[1] and n[2] to order of each ODE which is 2 in our case. nmax is the order of the highest order ODE and is used in defining the arrays. But in each loop, we use n[j] where j ranges from 0 to m-1 for each ODE. The three ODEs are defined in commands 9,10,11 and later the initial values are defined. We used symbol y for dependent variable and it takes two indices, the first one for the equation number in the system and the second for the derivative order. In 20, we have a loop which adds the initial conditions to the initial solution symbol. in Command 21, p is the number of iterated integral series terms that will be solved. This variable was m in the n order ODE mathematica code but its name has been changed to p here in the code for the system of ODEs solution. In commands 26-30, the first loop  For[j = 0, j < m, j++, is always over all equations in the system but rest of the logic is the same except that every ODE can have dependence on any element(derivative of some order) of any other ODE in the system which is captured by the this program using loops.

22. Array[Zi, {m, nmax + p - 1}, {0, 0}];

Here is a small program to calculate the analytic series solution for a system of m first order equations. Here is the very simple problem on which I used it 

[$]x'=y[$],  [$]x(0)=x_0=1[$]
[$]y'=6x-y[$],   [$]y(0)=y_0=-2[$]

In the following mathematica code, I have replaced  x by y[1], and y by y[2] and so on till y[m] for a set of m first order differential equations. Of course all the differential equations would have to be input by hand but I have tried to automate it as much as possible.
Here is some explanation to use the problem. Command 2 defines the number of first order equations in the system. I have explicitly defined arrays/list varaibles as compared to previous programs. In command (5) and (6) you have to specify the ODEs. Command (7) defines an array of inital values that is populated in command (8) and (9) which can be omitted in case of general initial values. Command (15) defines the number of iterated integral terms that will be included in the expansion. The brain of the method is in command 17, 18, 19, 20 the last three of which have three loops each. command 21 gives the answer which I have calculated and compared with closed form solution. I have shown the series solution at the end.

1.[$]\text{ClearAll}[Z,t,y,\text{Zi},\text{Wi},\text{Xi},X,\text{y0},i,\text{i1},m,n,\text{ZAns}][$]
2.[$]m=2;[$]
3.[$]\text{Array}[Z,m][$]
4.[$]\text{Array}[y,m][$]
5.[$]Z[1]\text{:=}y[2][$]
6.[$]Z[2]\text{:=}6 y[1]-y[2][$]
7.[$]\text{Array}[\text{y0},m][$]
8.[$]\text{y0}[1]=1[$]
9.[$]\text{y0}[2]=-2[$]
10.[$]n=15;[$]
11.[$]\text{Array}[X,m][$]
12.[$]\text{For}[j=1,j\leq m,j\text{++},X[j]\text{:=}\text{y0}[j]][$]
13.[$]\text{Array}[\text{Zi},m,n+1];[$]
14,[$]\text{Array}[\text{Wi},m,n+1];[$]
15,[$]\text{Array}[\text{Xi},m,n+1];[$]
16.[$]\text{Array}[\text{ti},n+1];[$]
17.[$]\text{For}[j=1,j\leq m,j\text{++},\text{Zi}[j][2]=(Z[j]\text{/.}t\to \text{ti}[2]);][$]

18.[$]\text{For}[j=1,j\text{$<$=}m,j\text{++} ,[$]
[$](\text{For}[i = 2, i \text{$<$=} n, i\text{++},[$]
[$](\text{Zi}[j][i + 1]=0;\text{For}[k=1,k\text{$<$=}m,k\text{++},[$]
[$](\text{Zi}[j][i + 1]=\text{Zi}[j][i + 1] + D[\text{Zi}[j], y[k]]*(Z[k] \text{/.} t \text{-$>$} \text{ti}[i + 1]));]);]);];[$]

19.[$]\text{For}[j=1,j\leq m,j\text{++},(\text{For}=\text{Zi}[j];[$]
[$]\text{For}[k=1,k\leq m,k\text{++},(\text{Wi}[j]=(\text{Wi}[j]\text{/.}y[k]\to \text{y0}[k]))]]);];[$]

20.[$]\text{For}[j=1,j\leq m,j\text{++},(\text{For}=\text{Wi}[j];[$]
[$]\text{For}[\text{i1}=i,\text{i1}\geq 2,\text{i1}\text{--},(\text{Xi}[j][\text{i1}-1]=\text{Integrate}[\text{Xi}[j][\text{i1}],\{\text{ti}[\text{i1}],0,\text{ti}[\text{i1}-1]\}])];[$]
[$]X[j]=X[j]+(\text{Xi}[j][1]\text{/.}\text{ti}[1]\to t);)]][$]

21.[$]\text{For}[j=1,j\leq m,j\text{++},(\text{ZAns}[j]=\text{Collect}[X[j],t,\text{Simplify}][$]
[$]\text{//}\text{PolynomialForm}[\#,\text{TraditionalOrder}\to \text{False}]\&)][$]

1. in which interval [0, T] does a solution exist?
It is a series solution and I am sure there are many other extensive mathematical methods that can help determine given a series on which interval it converges and is valid. There is however a very simple mathematica check to determine the validity of the solution. Let us say I am given an ODE problem and I have found a series solution using the method of iterated integrals. If the series solution is in t, For any given t, I can plug the series solution in the ODE and see how well the ODE is satisfied there. IF the error is extremely small, it means that approximation is very good. Let me explain it with an extremely simple example. 
Here is the ODE, I am trying to solve. 
[$]y'=f(\tau ,y(\tau ))=\frac{y}{\sqrt{\tau }},\text{    }y(0)=.5[$],   [$]t_0=0[$]
I have the series solution to say eight terms here.
[$]Y=0.5 +1. \sqrt{t}+1. t+0.666667 t^{3/2}+0.333333 t^2+0.133333 t^{5/2}[$]
[$]+0.0444444 t^3+0.0126984 t^{7/2}+0.0031746 t^4[$]
Obviously this solution should satisfy the original ODE. Let us see how well it satisfies the ODE at different values of t.
I use the mathematica command to evaluate the goodness of solution at t=.05;
[$]D[Y,t]-\frac{Y}{\sqrt{t}}\text{/.}t\to .05 [$]   and get the answer  -8.87329*10^-8  (This value would be zero if the ODE would be perfectly satisfied at that value of t given the series solution)
Now I evaluate it at t=.5 using mathematica command
[$]D[Y,t]-\frac{Y}{\sqrt{t}}\text{/.}t\to .5 [$] and get the answer  -0.000280598
let us see what we get at t=1 
[$]D[Y,t]-\frac{Y}{\sqrt{t}}\text{/.}t\to 1 [$]and I got the answer -0.0031746
Now we try to find how good the solution is at t=5 
[$]D[Y,t]-\frac{Y}{\sqrt{t}}\text{/.}t\to 5[$] and I get the answer -0.887329

So you see how the solution deteriorates with increasing time. You could add more terms if you need more accuracy at larger values of t and you could always plug the series solution in the ODE using mathematica, evaluate it for a certain value of t and see how close the result is to zero and you could know how good the approximation is.
