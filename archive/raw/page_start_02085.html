Friends, I want to try to explain how we can convert random variables with one density into random variables with a different density by multiplication of a Z-series/Hermite Series.

If we know moments of a random variable, we can easily find its Z-series representation by several of the methods we have used earlier particularly we can use a multidimensional Newton root-search method to find coefficients of a Z-series so that its moments exactly match the specified moments. This method works very well for a large class of random variables of the kind that interest us.

Suppose we have two random variables and their Z-series representation are known and they share the same underlying Z (i.e are perfectly correlated), we can use a simple series multiplication (by a yet unknown Z-series) to convert from one random variable to another random variable. 

if we know the Z-series representation of two random variables X and Y to nth order (would require knowledge of n+1 moments in general to be used with Newton root search to find the Z-series representation) and these Z-series representations are given as

[$] \, X(Z)\, = \, \sum\limits_{n=0}^{N} \,a_n \, {Z}^n\,[$] 
[$] \, Y(Z)\, = \, \sum\limits_{n=0}^{N} \,b_n \, {Z}^n\,[$] 

Z-series is a power series in Z.
Suppose we have found out all the coefficients in power series of X and Y above with multi-dimensional root-search method.
suppose there is a third random variable that we want to multiply to X(Z) in order to convert it into Y(Z), and it is given as W(Z) defined as following but its coefficients are still to be found.

[$] \, W(Z)\, = \, \sum\limits_{n=0}^{N} \,c_n \, {Z}^n\,[$] 

We know from our previous work that if three variables share the same underlying Z, the following must hold that random variable in LHS is a product of W(Z) and X(Z)

[$] \, Y(Z) \, =\, W(Z)\, X(Z)[$]

which can be written in power series form as

[$] \, \sum\limits_{n=0}^{N} \,b_n \, {Z}^n\, = \,  \Big[\, \sum\limits_{n=0}^{N} \,c_n \, {Z}^n\, \Big] \, \Big[\, \sum\limits_{n=0}^{N} \,a_n \, {Z}^n\, \Big] [$]

You can find the coefficients of W(Z) required to convert X(Z) into Y(Z) using power series manipulation but in extreme cases when coefficients of given Z-series are very small, you might have to use high-precision mathematics to correctly find the coefficients of W(Z).

In the context of matching moments of our normal random number generator, our generated density is not a true normal and has very small amount of higher cumulants after second cumulant (since deviation from normality is very small). We might need high-precision mathematics since coefficients on the Z-series that represents the generated density would be extremely small especially as we go to higher order. We have already done matching moments of random variables only to eighth moment but the method can be used to quite higher order and there is a possibility that we will need high precision mathematics for that.

If precision could be maintained by using high precision mathematics, we can simply use power series inversion to find the Z-series that needs to multiplied with our defective generated normal to convert it into a perfect normal. However, some other advanced method could possibly be used that matches coefficients without power series inversion.
Again in case of normal random generation, our target density Y(Z) is represented by Z which means that  [$]b_0=0, \, b_1=1, \, b_n=0  \, , {n>1}[$]
Our given density of generated normal random variables X(Z) would have all even coefficients as zero (if we use antithetic variates method) and all odd coefficients as non-zero but all odd coefficients greater than one would be very small as generate density is not very far from normal density. This can also be helpful in root-search since coefficients of generated density would be very small and very close to given guess from coefficients of true density.
We have to find W(Z) so that after multiplication with W(Z), our generated normal density X(Z) goes to true density Y(Z). This can be done with power series manipulation.
In the above explanation, I have done all the mathematics in the form of Z-series but you can later convert them to hermite series if you like since both are perfectly interchangable.

This is an easily do-able problem but might require special high-precision mathematics especially if we want to match higher order moments. In principle, the mathematics required to do this is very straightforward but I can possibly see that there might be difficulties in maintaining precision.
