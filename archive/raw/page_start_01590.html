I am writing this post to inform friends about enhancements I have made in the Newton (Matrix) root search method in high dimensions. As most friends would know that I have been using Newton root search in high dimensions in order to fit (first eight) parameters of the Z-series polynomial so that moments of the standard normal based (7th order) polynomial exactly fit the (first eight) moments prescribed by the user or put forth in calculations of various other problems.
Though most of the time, high dimensional Newton Iteration converges, there is no guarantee it would always do so. I also particularly noticed that in some other problems Jacobian matrix of derivatives would be available but for some other reason, matrix inversions would be poorly scaled due to bad condition number and Newton would strongly diverge as if it were blowing. There are a large number of other reasons when we would have a valid Jacobian and all other information calculated but Newton or other optimization method would still diverge for one reason or another. The method I present wants to help friends in all of the above conditions when multidimensional Newton root finding/optimization fails, and we are left aghast what to do to solve our problem.
First Introduction to Newton Root Finding Method.
In Multiple Dimensions, for finding K zeros of a K dimensional function F(X), we have to divide it with its K X K dimensional Jacobian as 
For nth iteration, we have
[$] X_{n+1} \, = \, X_n \, - \, {[J_F(X_n)]}^{-1} \, \, F(X_n) \,[$]
We also suppose that there is an objective function associated with this root-finding/optimization problems. We call it original objective function in what folllows.
This Objective function is denoted as  [$]OBJ=G(X_{n+1})[$]. This objective function is applied on the updated value [$]X_{n+1}[$]
However depending upon the problem and due to a large number of possible reasons, the above method does not converge all the time even when theoretically the zeros could be found.
I have been able to find a way using which the method could still be made to work. I have applied it to Newton root-finding equations, but the method could equally be applied to high dimensional numerical optimization problems.
I introduce a scalar parameter in the Newton root-finding/Optimization update equations. We optimize the value of this scalar parameter by Newton second order optimization so that Objective function in our original problem is maximized/minimized. 
[$] X_{n+1} \, = \, X_n \, -\, h_m \, {[J_F(X_n)]}^{-1} \, \, F(X_n) \,[$]
[$]h_m[$] is the scalar parameter introduced in optimization.
Please note that we have done all the hard work to calculate Jacobian in original problem and we use it to calculate the update. Now, all we need to do is to multiply this matrix update with our introduced scalar parameter repeatedly and use the original objective function repeatedly for Newton optimization iterations on the scalar parameter. 
We start with an initial value of [$]h_m=1[$], and perturb it to find first and second derivatives of the objective function with respect to [$]h_m[$]. Please note that we have already done the hard work to calculate the jacobian and it does not need to be recalculated for any further analytics on [$]h_m[$] and we simply reuse the already calculated value of Jacobian every time. Now we find the optimal value of [$]h_m[$] using the second order Newton optimization equation as

[$]h_{m+1} \, = \, h_{m} \, - \, \frac{\partial OBJ}{\partial h_m} \, {[\frac{\partial^2 OBJ}{\partial {h_m}^2}]}^{-1} [$]
So that the objective function is optimized (for [$]X_{n+1}[$] associated with [$]h_m[$]) given the value of jacobian we had once calculated.
This way we can find a value of scalar [$]h_m[$] that maximizes the Objective function. Many times when our matrices are badly scaled (or due to many other possible reasons that straightforward optimization fails), there is usually more than enough information in the Jacobian to take an explicit scalar correction and start working robustly again. 
So basically there are two levels of optimization in it. First there are N steps in original optimization where we calculate jacobian each time and for each of the nth step (leading to N steps in total), we do M optimizations on the scalar parameter [$]h_m[$] so that result of the original nth step optimization is best optimized. Nested M optimizations are very simple and fast (if the objective function is simple) because we do not have to recalculate the Jacobian every time for mth step.
I am very sure that this method can be applied on difficult optimization problems universally and therefore I am presenting it for friends here.
