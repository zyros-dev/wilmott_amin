Friends, to find a very good value for initial guess for coefficients when fitting Z-series moments to data moments, we can use the method given in this wikipedia link "Polynomial Regression". We would have to use this initial seed method with original data values (and not with moments of the data).

https://en.wikipedia.org/wiki/Polynomial_regression

Please look below the heading on the wikipedia link above: Matrix form and calculation of estimates 
There you can specify the data values y, and design matrix of powers of standard normal and then find the coefficients beta.
In order to find the value of standard normal (whose powers have to be used in design matrix in the same row as particular data value) associated with each data value, I first sorted the data. Then I divided the normal density into equal probability mass subdivisions with number of subdivisions equal to number of data values (these are naturally sorted). Then I assigned sorted normal values to sorted data values in increasing order. In the design matrix, I used the value of powers of Z that was assigned to the data value in the same row.

I have written a matlab program to do this and would share it with friends later today or tomorrow.

function [ZZ] = StandardNormalIdealDesity(Ndata)
%Ndata is number of data points in sample, for which we want to find the
%coefficients of the Z-series.


if (rem(Ndata,2)==0)
    NnMid=Ndata/2;
    ZZ(NnMid+1)=norminv(.5+1/Ndata*.5);
    ZZ(NnMid)=norminv(.5-1/Ndata*.5);
    for nn=2:NnMid
        ZZ(nn+NnMid)=norminv(.5+(nn-.5)*1/Ndata);
        ZZ(-nn+1+NnMid)=norminv(.5-(nn-.5)*1/Ndata);
    end
end

if (rem(Ndata,2)==1)
    NnMid=(Ndata+1)/2;
    ZZ(NnMid)=0;
    for nn=1:NnMid-1
        ZZ(nn+NnMid)=norminv(.5+(nn)*1/Ndata);
        ZZ(-nn+NnMid)=norminv(.5-(nn)*1/Ndata);
    end
end

function [c0,c] = CalculateZSeriesCoeffsByIdealMeasure02(data)
%data is (array of) sample observations of random variable whose Z-series
%Coefficients have to be found.


Ndata=length(data);
[ZI] = StandardNormalIdealDesity(Ndata);

Sdata=sort(data);

Y(1:Ndata,1)=Sdata(1:Ndata);
for nn=1:Ndata
    X(nn,1)=1;
    X(nn,2)=ZI(nn);
    X(nn,3)=ZI(nn).^2;
    X(nn,4)=ZI(nn).^3;
end

coeff=inv(X'*X)*(X'*Y);

c0=coeff(1,1);
c(1:3)=coeff(2:4,1);


end

After finding the values(from Z-series inversion of data points) of hermite polynomials associated with data, we can set up our regression in two parts. The first part would have a constant, any dummy variables and first hemrite polynomials and this part would be solved like we solve classic multivariate regressions.  The second part would consist of all higher hermite polynomials whose effects would be added independently on top of the solution from first part. Friends, I was playing around with addition/subtraction of densities using cumulants in our Z-series framework. It works quite well when we know the cumulants of two densities and we can convert them into Z-series and also add or subtract the cumulants to find the cumulants of resulting density which can again be shown in a Z-series form. 
The problem occurs when it becomes difficult to find Z-series of a density from its cumulants and our density construction programs fail to work successfully. To understand the reason behind this failure to construct "density with matching moments" phenomenon, we have to understand that Z-series is natural to only normal like densities that deviate just enough from normal density. For the kind of positive densities that take a very extreme right tail, it is much more natural to expand the random variable in terms of Laguerre polynomials instead of hermite polynomials. And once we have a fitted Laguerre polynomials to match the density of a random variable, we can easily convert the Laguerre representation to hermite polynomial form.
So I think that attempts to fit all sort of densities to orthogonal polynomials should shift focus from research solely on fitting hermite polynomials towards greater research on Laguerre and other related orthogonal polynomials. I am quite sure that positive densities with huge skew and accompanying kurtosis that become very difficult to match using hermite polynomials can very easily and parsimoniously be matched by polynomials that are more natural to that kind of target densities. And when needed, we could convert them into a hermite polynomial form with simple calculus. 
We have large applications of long tailed densities and therefore, I thought that I would try to write a program that works with Laguerre polynomials upto eight order and just does what our earlier Z-series density fitting program did with hermite polynomials.

Local supply and demand pressures can also cause option prices to deviate from their true backward implied values. I am not considering stochastic volatility explicitly in my analysis today but will try to re-do the analytics again after including the effect of stochastic volatility. 
We know that a call price is given as

[$]C_t \, = \, \exp(-r (T-t) ) E \Big[ (X_T \, - K)^{+} | \mathcal{F}_t \Big] \, [$]

We know that (from option implied density or from historical analysis or from some combination of these and other factors)

[$]\, X_T \, = X_t \, + \, a_1 \, Z \, \, + \, a_2 \, (Z^2-1) \, \, + \, a_3 \, (Z^3 -3 Z) \, + \ldots[$] 

Substituting the value of [$]X_T[$] in above equation, we have

[$]C_t \, = \, \exp(-r (T-t) ) E \Big[ (X_t \, + \, a_1 \, Z \, \, + \, a_2 \, (Z^2-1) \, \, + \, a_3 \, (Z^3 -3 Z) \,  \, - K)^{+} \, | \mathcal{F}_t \, \Big] \, [$]

We can convert the above expectation into an explicit integral but first we would have to solve for the value of Z for which [$]X_T[$] would become equal to strike K. We call this particular value of  Z as [$]Z_K[$]
So writing in an integral form, we get

[$]C_t \, = \, \exp(-r (T-t) ) \int_{Z_K}^{\infty}  \Big[ (X_t \, + \, a_1 \, Z \, \, + \, a_2 \, (Z^2-1) \, \, + \, a_3 \, (Z^3 -3 Z) \,  \, - K)  \, \Big] \frac{\exp[-.5 \, Z^2]}{\sqrt{ 2 \pi}}\, dZ [$]

We can analytically solve the above integral as

[$]C_t \, = \, \exp(-r (T-t) )   \Big[ (X_t \,-K) (1- P(Z_K)) \, +\frac{\exp[-.5 \, {Z_K}^2]}{\sqrt{ 2 \pi}}\, (\, a_1  \, \, + \, a_2 \, Z_K \, \, + \, a_3 \, ({Z_K}^2 -1) \, )  \, \Big] \,[$]
[$]= \, \exp(-r (T-t) )   \Big[ (X_t \,-K) (1- \Phi(Z_K)) \, + \, \phi(Z_K)\, (\, a_1  \, \, + \, a_2 \, Z_K \, \, + \, a_3 \, ({Z_K}^2 -1) \, )  \, \Big] \,[$]

The above is an analytical formula for option price that can be used for any strike.
