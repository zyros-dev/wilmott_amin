Until I wrote a good stochastic optimization routine for finding the optimum values of stochastic parameters. Since I always believe that I should share basic fundamental research with friends even though sometimes I might not want to share everything like complete trading algorithms as in this case. Therefore, I decided to share my stochastic optimization program with friends.
It is a surprisingly simple program but worked like gold for me. You have to provide some reasonable guess for the stochastic parameters that are to be optimized. And define a reasonable large step. The algorithm then iterates in the direction of increasing objective function with the large and coarse step added and subtracted to parameters iteratively. When the algorithm stops improving the objective function, the step is cut to .8 of the initial value and the algorithm starts iterating again. Each time algorithm stops improving the objective function, we decrease the step size by a ratio of .8 (or some other suitable ratio). Finally, the algorithm converges to some point with little variation and the best value of objective function. Due to random nature of stochastic processes, many times, the final convergence point is entirely different from the points where the algorithm converged with coarse steps. 
The good thing about the algorithm is that it explores the whole territory in the direction of increasing objective function with large and coarse steps at the start, so it does not easily get bogged down by local minima. And as it refines the step size in successive rounds of searches, it almost always finds a suitable value of the parameters that optimize the objective function very well.
In my case all the parameters shared the same probable range in which they can take values and therefore shared the same step change but in general the domain in which different stochastic parameters could take values would be different for every parameter of the stochastic process and in those cases the step change in each stochastic parameter would be made proportional to the standard deviation of the probable range(in the same common step ratio multiplied with standard deviation of every parameter) in which the particular parameter can take values. The above modification should work well but there will be some cases in which you will need to modify it for different step of some of the parameters.
I am sure that friends who optimize their stochastic neural networks with other optimization routines will really find my new function valuable for them. I am sure if the algorithm does not always work better than existing optimization algorithms for stochastic processes, quite a few times it will be very valuable as I found it of great value in my research.

The function in the post above optimizes the weights/parameters when it is given an objective function that has to be optimized. In my case the objective function is the output of a small independent function that takes some time series parameters. 
In a neural network, the objective function will represent the goodness of fit to the target output. In optimizing weights of a neural network, you can also use mean squared error between network output and the target value, but this mean squared error would have to be minimized while I am maximizing my objective function. I want to explain the program in context of neural networks.

Here is the function I am using to calculate the objective function

[ObjOld] = NetworkEvaluationFunction(Xt1,Xt2,Price0,VarLogR,Tl,w1,w2,w3,w4,w5,w6);
.
Here network evaluation function gives the result ObjOld that you can substitute with sum of mean squared errors between neural network calculated values of the target function and actual values of the target function. Xt1, Xt2, Price0, VarLogR, T1 are input arrays that are required to calculate the objective function given the network weights w1, w2, w3, w4, w5, w6.
We want to calculate the weights w1, w2, w3, w4, w5, w6 in a neural network so that ObjFunction/ObjOld is maximized or alternatively any mean squared error/loss function is minimized.
If you have a multi-layered neural network, just add all the various weights on different layers sequentially (possibly even using looping to calculate objective function with all weights sequentially one after the other) in main optimization loop and the algorithm would optimize it well.  

Here is the main optimization loop of the program that repeats the optimization over six weights a thousand times.
In my case all parameters were supposed to be between -1 and 1 and therefore I used just one single value of Delta (which is projected change in weights in a single optimization) for all the weights. You will need some idea about the domain on which weights will take values. if domains of various weights are different you can use a different value of Delta proportional to domain and decrease values in larger domain slightly faster.
As I mentioned Delta is the projected change in weights and this starts with large values as if we are evaluating on a coarse grid. I have taken an initial value of Delta =.15 when my domain is for weights is between -1 and 1 but I think an initial value of .2 or .25 might have worked even better in some difficult cases. 
We do 1000 iterations of the optimization over weights loop. At the start of the optimization, we set the value of variable Update equal to zero. Whenever even a single weight is updated, the value of update turns true. However, when no value is updates, we know it is time to decrease the step size Delta by a suitable value. I have chosen this value to .8 but please feel free to experiment. After decreasing the value of Delta, the optimization starts again with a smaller step size as if on a slightly finer grid. This way value of optimization step Delta continues to decrease and optimization search for best weights is done on a successively finer grid.

Though I have described in the previous post but let me summarize the algorithm again that it optimizes weights of neural network sequentially in the direction of increasing objective function, initially with a large step as if on a very coarse grid. When coarse grid optimization ends, it slightly refines the grid and starts optimizing again and then refines the grid again after it is finished optimizing at that level. Until it reaches very close to the optimum value of weights. There is no fixed grid per se, but the step size towards optimizing direction is quantized as if on a grid.

Friends, I had worked with the above algorithm in case of a single neuron with six inputs and it worked great. I was really expecting that it would work well on multi-layered network with one intermediate layer but when I tried the above algorithm on a neural network with intermediate layer of neurons, its performance was poor.
That prompted me to think how we could systematically assign initial weights to a neural network before we enter the optimization loop.
There are so many different kinds of neural networks, but my observations are only valid for neural networks that are meant for prediction.
Let us consider a simple toy neural network with five inputs and three neurons in intermediate hidden layer and finally one neuron at end that collects the output of three hidden layer neurons and gives us the final result as its output.
One observation that I was able to think was that weights between inputs and hidden layer should be so that output of first hidden neuron should be orthogonal to both the outputs of second and third neuron in hidden layer. Similarly, output of second neuron should be orthogonal to first and third neuron and so on for the last third neuron in the hidden intermediate layer.
This prompts us to consider several training strategies. For example, optimize the weights on inputs to first hidden layer neuron with zero weights on inputs to second and third hidden intermediate neurons. Once the final output has been perfectly optimized with initial weights leading to first hidden intermediate layer neuron, it means that one factor has been well calibrated. 
Now train the weights leading to second intermediate layer neuron given the weights on first intermediate layer neuron that we had previously optimized. So, we do not alter the pre-optimized weights of first neurons and only alter the weights of second neuron but again do not yet alter the weights of third neuron and keep them at zero value. This way, second intermediate layer neuron will pick the effects of second orthogonal factor after first factor has already been perfectly optimized by first neuron in hidden layer. 
In the last, we keep the optimized weights of first and second intermediate layer neurons fixed and alter the weights of third neuron so that it can pick the effects of third orthogonal factor. 
After this step, if desired, we can run some iterations of gradient descent optimization algorithm on all of the network and hopefully the final values would not change by a large amount.
